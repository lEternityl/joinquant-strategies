# JoinQuant 量化策略集

基于 [聚宽（JoinQuant）](https://www.joinquant.com/) 平台开发的 A 股量化策略集合，以**日内回转做 T**系列为主体，附带资金流跟踪、趋势选股、日历效应等独立策略。所有策略均针对 A 股 T+1 制度做了适配。

## 策略清单

## 使用方法

1. 注册并登录 [聚宽平台](https://www.joinquant.com/)，进入策略编辑器
2. 将策略代码粘贴到编辑器中（或通过研究环境上传）
3. 做 T 系列策略回测需选择**分钟级**频率；其余策略按文件头部说明选择频率
4. 修改文件顶部的可调参数（标的代码 `SECURITY`、网格步长、止损线等）
5. 先回测验证，再模拟盘跟踪，最后小资金实盘

> **A 股 T+1 说明**：当日买入的股票当日不能卖出。做 T 系列策略通过"底仓 + 做 T 仓"冲销的方式模拟 T+0——正向回转先用现金买入 T 仓、收盘前卖出等量底仓；反向回转先卖出底仓、收盘前买回同等金额。

## joinquant-skill

本仓库以 submodule 形式引入 [joinquant-skill](joinquant-skill)——聚宽 AI 编程技能包，包含 API 文档检索、策略模板、示例等，可配合 AI 编程工具（如 Claude Code）使用。克隆时需加 `--recurse-submodules` 参数：

```bash
git clone --recurse-submodules https://github.com/lEternityl/joinquant-strategies.git
```
